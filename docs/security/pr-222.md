# Worker breaks review (upstream PR 222)

Reviewed the original upstream project PR 222 at 874434cca7fbd2f4171c237b2498bfc8113a1ec1. This adaptation adds a visual break for idle or finished desk agents; it does not suspend, stop or write to their terminal.

The server validates eligibility and the caller's current floor. Helpers, shells, meetings, board stations and missing worktrees are excluded. Repeated start requests preserve the break timestamp; recall clears it. A status update showing work, input required or an unavailable worker clears the marker before broadcasting. State changes go through WorkerManager's persistence and update path. Restart restores workers offline at their desks, ending breaks.

Hosted floors advertise `workerBreaks`; the proxy refuses older hosts explicitly rather than sending an unsupported command. No dependencies, external requests, process execution or filesystem permissions were added. The existing office permission model remains the authority for shared floor controls.

Browser checks covered all eleven destinations, terminal access while away, recall, return to work, departure from the current position, helper terminal access and office/castle/station transitions. Routes are visual approximations using existing navigation and fixed office props; breaks are available only on the office map.
