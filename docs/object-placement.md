# Object placement

Open **Menu → Customize objects** on an office floor. Click or tap a plant, rug or coffee table; its gold outline marks the selection. Drag to move it across its horizontal plane. Rotate and Scale turn horizontal drags into smooth adjustments; numeric fields provide precision, with optional 15° rotation snapping. Uniform size ranges from 0.25× to 3×. Reset rotation, Original size and Reset Transform restore defaults. Confirm / Deselect keeps changes and releases the selection. Close with ✕ or Esc to resume gameplay.

Complete object bounds stay inside the office and below the ceiling; red feedback means the attempted change was rejected. Objects may overlap intentionally. Movement preserves original height and grab offset. Mouse and touch use the same pointer controls. Other windows block scene selection.

In **3D**, walking stays active while the editor is open: use WASD or the arrow keys to reposition the player, including during an object drag. Hold the right mouse button and drag to look around in first person or orbit in third person; left-drag selects and edits objects. The cursor stays free for selecting objects and using the panel. While dragging in Move mode, the object follows the cursor as the player/camera moves. Numeric inputs pause held movement when focused, and other windows pause navigation until closed. The 2D editor retains its stationary overhead view. Closing the editor restores normal mouse-look.

Each opted-in object has a stable ID, position, Euler rotation and scale. The office server owns the shared layout and broadcasts previews during dragging, rotating and scaling to every player on that floor in both 3D and 2D, even when their editor is closed. Previews are sent at most every 40 ms; completed adjustments flush immediately. The panel shows **saved to shared office** only after the server has written the layout to disk. A player joining, reloading, reconnecting or switching floors receives the authoritative snapshot. If two players edit the same object, the server's last accepted update wins. Different objects and floors remain independent.

Layouts live in the office's `.agent-office/placements/<hex-floor-id>.json`, including hosted floors, so they do not depend on a member's remote checkout. Atomic replacement protects the previous file during writes. Long drags are checkpointed every 300 ms; completed gestures, disconnects, floor departure and normal office shutdown flush pending server changes. Failed disk writes retain dirty data for retry and notify the editor. Editing requires an office connection; an interrupted pending edit is retried on reconnect. The current editable scenery belongs to the `office` map; another map neither receives nor alters it.

Browser localStorage remains a cache. Old personal placements are imported only for objects missing from the server's layout, so an old browser cannot overwrite an existing shared placement. Invalid records and protected IDs are ignored. Clearing browser data does not remove the shared layout. Back up the office's `placements` directory with its other `.agent-office` data.

Gameplay fixtures, seats, desks, doors, boards, lamps, vehicles, animated props and plants managed by wing expansion remain protected. Existing interactions work normally outside customization mode. The editable set covers ordinary office plants, rugs and the coffee table. Add safe scenery with `editable(object, stableId, label, collider?)` from `features/object-placement/model.ts` and its default transform in the shared `PLACEMENT_DEFAULTS` allowlist; another map needs a matching server namespace before opting in. Objects with externally managed anchors or simulations need an adapter first. Collider bounds follow transforms. Server validation protects IDs, the active floor/map, fixed height, supported rotation and uniform scale limits. The feature installs through client, message, snapshot, state-slice and lifecycle registries, and uses the existing modal/focus system.

Verify with `npm run typecheck`, `npm test`, `npm run build` and `node --import tsx scripts/e2e-object-placement.mjs`.
